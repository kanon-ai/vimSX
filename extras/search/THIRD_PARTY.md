# Third-party components

GREP.COM and FIND.COM were built with SDCC 4.6.0 #16555. Each link map lists `_modulong.rel`, `_divulong.rel`, and `crtenter.rel` from `z80.lib`.

The corresponding unmodified sources and GPL text are included in [third_party/sdcc](third_party/sdcc). They retain their GPL v2-or-later notices and SDCC linking exception. The exception permits linking the runtime without, by itself, imposing GPL terms on the entire executable. Independently written search code and the LS-derived startup/build support use [MIT](LICENSE.txt).

- [Upstream SDCC r16555 sources](https://sourceforge.net/p/sdcc/code/16555/tree/trunk/sdcc/device/lib/): `_modulong.c`, `_divulong.c`, `z80/crtenter.s`.
- [SDCC library licensing](https://sourceforge.net/p/sdcc/wiki/SDCC%20Library%20Licenses/).

No emulator executable, BIOS, DOS system file, or boot disk is distributed here. The test fixtures are synthetic text generated by the included Python script.
