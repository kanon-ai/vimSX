MSXSH 用の簡易サンプルです。

DEMO.SH、MSXSH.COM、GREP.COM を同じディスク・ディレクトリに置き、
MSX-DOS の A> プロンプトから次のように実行してください。

  MSXSH DEMO.SH

MSXSH の中にいる場合は、先に exit で DOS に戻ってください。
シェルの入れ子実行には対応していません。

変数、引用符、&& / || による条件付き実行、3段パイプ、$? を試します。
パイプの出力は 1:apple banana、終了状態は 0 になります。
次の不一致検索では終了状態が 1 になります。
MSXSH 0.2 では if / for / 変数代入にも対応しました。
追加サンプルは MSXSH CONTROL.SH で実行できます。
CONTROL.SH は NAME / fruit / pattern / DEMO_MODE を設定して削除します。

ディスクへの書き込みはしません。
環境変数 MSXSH_DEMO を一時的に設定して削除するため、同名変数は未使用にしてください。
実用性・安全性は未確定の実験用サンプルです。コピーした環境で試してください。
