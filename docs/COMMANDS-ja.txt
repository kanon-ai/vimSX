vimSX コマンド早見表

■ MSX-DOS2で起動

  VIINT MAIN.C    内蔵V9968版で MAIN.C を編集
  VIEXT NOTE.TXT  外部V9968版で NOTE.TXT を編集

ファイル名を指定して起動すると、そのファイルを読み込みます。
引数を省略すると空の文書で起動し、保存先は TEXT.TXT になります。
既存の TEXT.TXT を編集する場合は、起動時に名前を指定してください。

■ ノーマルモード（画面下に NORMAL と表示）

  h / j / k / l   左 / 下 / 上 / 右へ移動
  カーソルキー    対応する方向へ移動。挿入中も使えます
  0 / $           行頭 / 行末の文字へ移動
  i               カーソル位置から挿入
  a               カーソルの文字の直後から挿入
  A               行末に追記
  x               カーソルの文字を切り取り（p / P で貼り付け可）
  dd              現在行を切り取り（小文字の d を続けて2回）
  yy              現在行をコピー
  p / P           行なら現在行の下／上、文字ならカーソルの後／前に貼り付け
  3dd / 3yy       3行を切り取り／コピー（行数は変更可）
  2p              同じ内容を2回貼り付け

■ 挿入モード（INSERT）

  Enter           改行
  Backspace       直前の文字を削除
  Esc             挿入を終えてノーマルモードに戻る

■ 検索と置換

ノーマルモードで入力します。/ または : で始まる操作は Enter で実行します。

  /文字列         次の一致を検索。文末に達すると先頭へ戻る
  n               同じ文字列の次の一致へ移動
  :s/旧/新/       現在行で最初の一致を置換
  :s/旧/新/g      現在行のすべての一致を置換
  :%s/旧/新/      文書内の各行で最初の一致を置換
  :%s/旧/新/g     文書全体のすべての一致を置換

例　:%s/count/total/g　　文書全体で count を total に変更
例　:s/仮//g　　　　　　現在行にある「仮」をすべて削除

検索・置換は大文字と小文字を区別する固定文字列方式です。
置換の旧文字列・新文字列に区切り記号 / は指定できません。
現版では u による取り消しは未対応です。

■ 入力形式とCPU（各コマンドの後に Enter）

  :ascii          半角40桁×25行のカラー画面に切り替える。i で入力開始
  :kanji          漢字画面に切り替える。i で本文の入力を開始
  :z80            turbo R のCPUをZ80に切り替える
  :r800           turbo R のCPUを高速なR800に切り替える

■ 保存と終了（各コマンドの後に Enter）

  :w              現在のファイル名で保存し、編集を続ける
  :wq             現在ファイルを保存。他方も未変更なら終了
  :q              両ファイルに未保存の変更がなければ終了
  :q!             未保存の変更を破棄して終了

操作例　VIINT NOTE.TXT で起動 → i → 本文を入力 → Esc → :wq → Enter

■ 行番号表示（通常モードで入力し Enter）
  :set number（:set nu）       行番号を表示
  :set nonumber（:set nonu）  行番号を隠す
  :SET NUMBER も使用できます。折り返しの続きには番号を表示しません。

■ 配色（ノーマルモードで入力し Enter）
  起動時はDOSの文字色・背景色を使用します。
  :color 1    青背景に白文字
  :color 2    黒背景に白文字
  :color 3    黒背景に濃い緑の文字
  :color dos  起動時のDOS配色に戻す
  半角画面と漢字画面で同じ設定を使用します。

■ 2ファイルの切り替えと共通レジスタ

  :e SECOND.TXT   2つ目のファイルを開く。存在しなければ新規作成
  :bn / :bp       もう一方のファイルへ切り替え
  :b1 / :b2       1番目／2番目へ切り替え（:b 1 / :b 2 も可）
  :wa             開いている両ファイルを保存
  :wqa            両ファイルの保存に成功したら終了

各ファイルの未保存の内容、カーソル位置、表示位置を保持します。
ファイル名はステータス行に表示します。3つ目は開きません。
既に開いているファイルを :e で指定した場合は、そのファイルに切り替えます。

例　最初のファイルで 3dd → :e SECOND.TXT → p → :wa
例　最初のファイルで yy → :bn → P

文書は各1MiB、計2MiBまで。文書と共通レジスタはV9968のVRAMを使用します。
レジスタは直近の yy / dd / x で更新され、ファイルを切り替えても保持します。
貼り付けで1MiBを超える場合は、内容を変更せずエラーを表示します。
:q! は両方の未保存内容を破棄するため注意してください。
