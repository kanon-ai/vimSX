# 入力・削除の描画最適化（2026-11-23）

通常版 VIMAP と従来描画版 VIINT / VIEXT の行末消去を最適化しました。
文字追加で行が長くなる場合は、すでに空白の領域を再消去しません。
ASCII画面で行が短くなる場合は、以前の文字が残る範囲だけを消去します。
画面全体の再描画では従来どおり行末まで消去します。
DOS漢字ドライバへの出力では、短くなった行の消去に従来の ESC K を使います。

V9968直接描画の VI9IN / VI9EX は既存のハードウェア描画を継続し、
今回のCOMバイナリは変更していません。

## 測定方法と範囲

`tests/benchmark.py` が同じ文書と同じ入力列を変更前・変更後に実行し、
エディタのキー読み取り入口間の**エミュレータ内時間**を測定します。
挿入モードへの移行、行の折り返しなど、その入力列で必要になる処理も含みます。
測定用エミュレータは共通の4MB対応openMSX、turbo Rプロファイルです。
Z80/R800はエディタのコマンドで切り替えます。

ホストPC上の実行秒数を性能値に使っていません。実機での測定結果ではありません。
CPU/VDPを高速化する設定変更や、エミュレータ本体の変更は行っていません。
`validation-performance.json` に変更前後の値・COMハッシュ・回帰試験結果を記録します。

## 回帰試験

- `tests/incremental_tail.py`: ASCII 40/80桁で、追加・Backspace・削除・日本語・改行結合・行削除・貼り付け・行番号を操作。差分描画と強制全面描画のVRAM内容を比較。
- `tests/exact_width.py`: 桁数ぴったりの折り返し、日本語境界、Enter/Backspace、行番号、上下スクロール、保存内容を確認。
- `tests/kanji_first_cell.py`: KANJI 40/80桁の先頭文字の欠けと保存内容を確認。
- `tests/regression.py`: 2ファイル間のカット＆ペースト、新規編集の保存内容を確認。
- BlueMSX+の通常版で、実際のキー入力による画面切り替え・色・行番号・編集・保存・終了を確認。

各試験の対象ビルドと実行結果はJSONを参照してください。
